# Personal desk colour

When a System Manager enabled *Allow users to choose their own colour* on **Desk Background Settings**, you can set your own colour and strength.

1. Open **User** (your own user record).
2. Tab *Settings* -> section *Desk Settings*.
3. *Desk Colour* (below *Desk Theme*) - pick a colour, or leave empty for the site default.
4. *Desk Colour Strength* - **Tint** (softer) or **Strong** (more vivid), or leave empty for the site default.

Save. Desk clears cache and reloads when your effective colour or strength changes.

If these fields are not visible, personal choice is disabled site-wide.

See also: [Site settings](/app/docs/en/red-background/site-settings).
