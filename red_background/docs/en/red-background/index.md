# Red Background

Apply a subtle Desk background tint so test and staging systems are easy to tell apart from production. Colour is a visual aid only - also check the site URL or hostname.

## How colours are chosen

1. **Standard** - stock Frappe colours (no tint)
2. **Site preset** - set by a System Manager on **Desk Background Settings**
3. **Personal preset** - optional on **User** when *Allow users to choose their own colour* is enabled

## Guides

- [Install the app](/app/docs/en/red-background/install-app)
- [Site settings](/app/docs/en/red-background/site-settings) - **Desk Background Settings**
- [Personal desk colour](/app/docs/en/red-background/user-settings) - **User** field below *Desk Theme*

Saving your own *Desk Colour* or **Desk Background Settings** clears cache and reloads Desk.
