# Hintergründe für Schreibtisch

Subtiler Desk-Hintergrund, um Test- und Staging-Systeme von Produktion zu unterscheiden. Die Farbe ist nur eine visuelle Hilfe - prüfen Sie zusätzlich URL oder den Hostname der Seite.

## Farbhierarchie

1. **Standard** - Frappe-Standardfarben (kein Tint)
2. **Seitenvoreinstellung** - System-Manager auf **Hintergrundfarbe Einstellungen**
3. **Persönliche Voreinstellung** - optional auf **Nutzer**, wenn *Benutzern erlauben, eine eigene Farbe zu wählen* aktiv ist

## Anleitungen

- [App installieren](/app/docs/de/red-background/install-app)
- [Seiteneinstellungen](/app/docs/de/red-background/site-settings) - **Hintergrundfarbe Einstellungen**
- [Persönliche Schreibtisch-Farbe](/app/docs/de/red-background/user-settings) - **Nutzer**-Feld unter *Schreibtisch-Design*

Beim Speichern der eigenen *Schreibtisch-Farbe* oder von **Hintergrundfarbe Einstellungen** wird der Cache geleert und der Schreibtisch neu geladen.
